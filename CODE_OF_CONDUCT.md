# Code of Conduct

## The short version

Be civil. Argue with the claim, not the person. Assume the other party
read the thing and disagreed anyway.

## The part specific to this project

This repository publishes predictions that turned out wrong, on purpose.
Four of six scored pre-registrations contain misses, and one of them
disproved the previous cycle's own diagnosis.

**Pointing out that something here is wrong is not rude — it is the
intended use.** A report that the tool found nothing useful, or that a
documented claim does not hold, is welcome and will be published as
found. What is not welcome is contempt: for a question, for a mistake,
or for someone else's stack.

## Unacceptable

Harassment, personal attacks, discriminatory language, sustained
disruption, publishing others' private information, and unwelcome
attention of any kind.

## Scope

Applies in issues, pull requests, discussions and any correspondence
about this project.

## Enforcement

Report to **shaun@reddmunro.com**. Reports are handled privately.
Responses run from a request to change behaviour up to a permanent block
from the repository. There is one maintainer, so there is no appeals
panel; if the maintainer is the problem, say so publicly — the project's
whole argument is that being caught is better than being trusted.

## Attribution

Informed by the [Contributor Covenant](https://www.contributor-covenant.org),
shortened deliberately: a code of conduct nobody reads protects nobody.
